# Atividade TypeScript


## O que foi feito

No projeto, foram explorados e aplicados na prática os seguintes conceitos:

- **Declaração de Variáveis**: Uso de `let` e `const`.
- **Tipagem Estática**: Definindo tipos explícitos para variáveis e parâmetros.
- **Funções Tipadas**: Criação de funções com parâmetros tipados e tipagem de retorno.
- **Estruturas Condicionais**: Utilização de `if` e `else` para controle de fluxo.
- **Manipulação do Console**: Exibição de informações e resultados com `console.log`.

---

## Sobre o Código

1. **Variáveis**:
   - Uma variável `nome` foi declarada usando `let`.
   - Uma variável `idade` foi declarada usando `const`.
   - Os valores das variáveis são exibidos no console.

2. **Funções**:
   - `somar(a: number, b: number): number`: Recebe dois números como argumento e retorna a soma deles.
   - `maiorDeIdade(idade: number)`: Recebe uma idade e verifica se a pessoa é maior ou menor de idade.

3. **Execução**:
   - No final do arquivo, as funções são chamadas e testadas, exibindo seus retornos diretamente no terminal.
